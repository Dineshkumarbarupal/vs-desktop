# FlowCode Studio

A local-first desktop editor built with HTML, CSS, JavaScript, Python and Eel.

- Open a folder from **File → Open Folder**.
- Click a file in Explorer to edit it.
- **Ctrl+S** saves; **F5** runs a supported script.
- **Ctrl+Shift+P** opens the Command Palette.

This is an original lightweight IDE foundation, not Microsoft VS Code and not a complete replacement for its extension ecosystem.
